# 三、页面结构与样式要求（从上到下）

**1. 导航栏**
- 二级页样式：左侧 36×36 返回按钮（圆角 12，白色 75% 底 + 1px 描边），中间标题「订阅详情」17px/600，右侧避让微信胶囊（用 `wx.getMenuButtonBoundingClientRect()` 定位）。
- 导航栏吸顶。页面滚动超过 8px 后加浅色底、底部分隔线和轻微投影（见 `detail-bottom.png`）。
- 本页**不显示底栏**。页面顶部保留与其他页面一致的柔光氛围背景。

**2. 主卡（`card.hero`）**
- 上半部分：54×54 服务 Logo（圆角 16，品牌色渐变 + 同色投影），服务名称 21px/700，分类 12.5px `--ink-3`，右上角状态胶囊。状态与颜色按规范 §2.2 映射：即将到期为橙色，正常为绿色，其他状态沿用现有判断。
- 下半部分「下次扣费区」：上方 1px 分隔线，背景是状态色从上往下渐隐（即将到期用 `rgba(255,241,230,.55)` → 透明；正常状态可用蓝色或不加底色）。
  - 小标签「下次预计扣费」12px。
  - 左侧金额 22px/700：有金额时用 DIN 字体、`--ink` 色；缺失时显示「金额待补充」，橙色。
  - 右侧日期（数字 DIN）+ 下方倒计时胶囊：≤7 天橙色，8–14 天蓝色，>14 天灰色。
- **本期进度条**（主卡底部）：6px 轨道，已过去的部分用状态色渐变填充，末端是一个白心、状态色描边的圆点。进度 =（今天 − 本期起始日）÷（下次扣费日 − 本期起始日）。本期起始日由计费周期从下次扣费日往前推一个周期得出。左下标签「本期 起始日」，右下标签「扣费日 扣费」。周期无法推算时（如自定义周期），隐藏整条进度条。

**3. 信息格**
- 2×2 网格：计费周期、付款渠道、分类、自动续费。格子之间用 1px `--hair` 分隔线。
- 每格：34px 图标块（圆角 11，按顺序用蓝 / 绿 / 紫 / 橙浅底配同色描边）+ 小标签 11.5px `--ink-3` + 值 15px/600。
- 自动续费的值前面加 6px 状态点：开启为绿色（带 3px 浅绿光圈），关闭为灰色。

**4. 提醒计划卡**
- 卡片标题「提醒计划」，右上角是通知状态胶囊（「通知可用」用蓝色胶囊加圆点；其他状态沿用现有文案，颜色按语义取）。**如果现有实现中这个文字可以点击跳转，保留跳转，并在胶囊末尾加一个小箭头。**
- 提醒节点：用蓝色浅底胶囊显示（高 34，圆角 11，数字 DIN），节点之间用蓝色虚线连接，末尾是一个 34px 橙色浅底的日历图标块，下面标注「扣费日」。节点数量和文案来自现有数据，节点多到放不下时允许横向滚动。
- 卡片底部是「最近提醒」信息条：上方 1px 分隔线，状态色从左向右渐隐的背景，左侧 28px 铃铛图标块。提醒无法发送时（如「请填写金额后接收微信通知」）整条用橙色，说明文字加粗；能正常发送时用蓝色，显示提醒时间（数字 DIN）。

**5. 本期处理卡**
- 标题「N 天后扣费」17px/700，其中天数用 DIN 字体、橙色；说明文字 12.5px、行高 1.6、`--ink-3`。
- 按钮：「确认已续费」全宽 `btn-soft`（浅蓝底，前面是蓝色实心圆加白色对勾）；下面一行两个等宽按钮——「稍后处理」用橙色浅底（`--orange-soft` 底、`--orange-line` 描边、橙色字），「已取消」用红色浅底（`--red-soft` 底、`--red-line` 描边、红色字）。按钮高 46、圆角 14、间距 10。
- 这张卡片的显示条件、标题天数和按钮状态都沿用现有逻辑（比如本期已处理后，按现有逻辑隐藏或改变状态）。

**6. 底部操作栏**
- 固定在页面底部，不随内容滚动；上方有约 24px 的页面底色渐隐，左右边距 16，底部加安全区 `env(safe-area-inset-bottom)`。
- 左侧「管理订阅」：白底 `btn-ghost`，前面是三个点的图标；右侧「编辑订阅」：`btn-primary`，前面是铅笔图标。两者宽度比约 1 : 1.7，高 50，圆角 16，间距 10。
- 页面内容底部留出约 108px 空白，保证滚到底时内容不被按钮挡住。

# 四、通用要求

- 单位：以 390 宽为基准，`rpx = px × 750 / 390`；1px 描边和分隔线保持 `1px` 不换算。
- 卡片：左右外边距 16，卡片间距 12，圆角 20（主卡 22），白色 86% 底 + 1px `--border` 描边。
- 字体：金额、日期数字、天数、计数统一使用 `--font-num`（DIN Alternate），并加 `font-variant-numeric: tabular-nums`。
- 颜色、圆角、阴影全部使用令牌，不要出现新的十六进制色值。服务 Logo 的品牌色沿用现有数据。
- 交互反馈：所有按钮按下缩放到 0.97，持续 160ms；颜色变化 260ms；默认缓动 `cubic-bezier(.25,.8,.25,1)`。
- 所有可点元素热区不小于 44×44。
