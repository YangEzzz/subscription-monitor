# 三、页面结构与样式要求（从上到下）

**1. 导航栏**
- 二级页样式：左侧 36×36 返回按钮（圆角 12，白色 75% 底 + 1px 描边），中间标题「新增订阅」17px/600，右侧避让微信胶囊（用 `wx.getMenuButtonBoundingClientRect()` 定位）。
- 导航栏吸顶。页面滚动超过 8px 后加浅色底、底部分隔线和轻微投影（见 `add-bottom.png`）。
- 本页**不显示底栏**。
- 页面顶部保留与其他页面一致的柔光氛围背景。

**2. 说明卡（主角卡 `card.hero`）**
- 上半部分：40×40 蓝色图标块 + 标题「记录一项持续支出」16.5px/700 + 说明文字 12px。
- 下半部分是**实时预览**，和上半部分之间用 1px 虚线分隔，左上角有「● 预览」小标题。预览用订阅列表行（`srow`）的样式，展示用户**正在填写**的内容：
  - Logo 背景 = 当前选中的品牌标识颜色（160° 渐变：原色提亮到 112%，过渡到压暗到 82%），Logo 文字 = 服务名称首字（取大写）；未填写时显示「?」。
  - 名称 = 服务名称输入值；未填写时显示占位文字，颜色 `--ink-4`。
  - 元信息 = 当前分类 · 下次扣费日（月日）。
  - 右侧：金额已填写就显示金额（DIN 字体），没填写就显示「金额待补充」（橙色）；下面是倒计时胶囊，颜色规则：≤7 天橙色、8–14 天蓝色、>14 天灰色。
  - 预览只是展示，不参与提交。

**3. 常用模板卡**
- 标题「常用模板」，右侧灰色胶囊「快速填充」。
- 模板横向滚动，右侧 15% 渐隐，暗示还能继续滑。每项宽 78，圆角 16，白底 + 1px 描边；内部是 40×40 品牌色 Logo + 12px 名称。
- 点击模板：执行现有的快速填充逻辑，该模板变为选中态（`--blue-soft` 底、`--blue-line` 描边、蓝色文字），预览同步更新。按下时缩放到 0.95。

**4. 基本信息卡**（区块标题「基本信息」17px/700 写在卡片外）
- 统一的**表单行**：最小高度 54，左右内边距 16；标签在左（15px/600），输入内容右对齐，**去掉原来的输入框外框**；占位文字 `--ink-4`。行与行之间用 1px `--hair` 分隔线（从左侧 16px 开始）。
- 必填标记：标签后紧跟红色 `*`（`--red`）。
- 分类行：右侧显示当前分类值 + 箭头，整行可点，按下时背景变 `rgba(21,22,28,.03)`。
- 品牌标识：标签单独一行，下面是 6 个 36px 圆形色块，两端对齐。选中的色块中间显示白色对勾，外圈加一道 2px、35% 透明度的同色环；切换时对勾和外环带回弹（`--ease-spring`）。色值沿用现有代码。

**5. 扣费信息卡**
- 金额行：左侧「金额」+ 小字说明「可稍后补充」；右侧是宽 176、高 40 的**组合输入框**，圆角 12：左段是币种按钮（浅蓝底、蓝色 DIN 文字 + 下拉箭头），右段是数字输入（DIN 17px，右对齐，占位「选填」）。聚焦时描边变 `--blue-line`，外加 4px 主色淡光圈。
- 下次扣费日行：右侧依次是倒计时胶囊、日期（数字用 DIN）、箭头，整行可点，打开现有的日期选择器。
- 自动续费、试用期：左侧标题 + 小字说明（沿用现有说明文字，包括随开关状态变化的文案），右侧开关。开关尺寸 50×30；开启时背景为主色渐变（`#4C76FF → #2448DA`）；滑块 24px 白色圆形，移动 480ms，使用 `--ease-spring` 回弹。

**6. 提醒节点卡**（区块标题右侧灰色胶囊「可多选」）
- 选项三列网格，间距 8；每项高 42、圆角 13，白底 + 描边，数字用 DIN。
- 选中：`--blue-soft` 底、`--blue-line` 描边、蓝色 600 字重，前面加对勾；按下缩放到 0.96。
- 卡片底部是「预计最近提醒」信息条：上方 1px 分隔线，浅蓝色从左向右渐隐的背景；左侧 32px 蓝色铃铛图标块，右侧上行小字「预计最近提醒」，下行显示蓝色时间（数字 DIN）。时间沿用现有计算结果，随选项实时更新。

**7. 补充信息卡**
- 备注、取消路径各占一块：标签单独一行，下面是高 86、圆角 13 的多行输入框，浅灰凹陷底（`--surface-sunken`）+ 描边。
- 聚焦时背景变白，描边变 `--blue-line`，外加 4px 主色淡光圈。
- 占位文字沿用现有文案。

**8. 底部操作栏**
- 固定在页面底部，不随内容滚动；上方有约 26px 的页面底色渐隐，左右边距 16，底部加安全区 `env(safe-area-inset-bottom)`。
- 「保存订阅」按钮：全宽、高 50、圆角 16，主按钮样式（蓝色渐变 + 主色投影）；按下缩放到 0.97。
- 校验和提交完全沿用现有逻辑。如果现有逻辑本来就有禁用态，禁用时降为 50% 透明度。
- 页面内容底部留出约 116px 空白，保证滚到底时最后一个输入框不被按钮挡住。

# 四、通用要求

- 单位：以 390 宽为基准，`rpx = px × 750 / 390`；1px 描边和分隔线保持 `1px` 不换算。
- 字体：金额、日期数字、计数统一使用 `--font-num`（DIN Alternate），并加 `font-variant-numeric: tabular-nums`。
- 颜色、圆角、阴影全部使用令牌，不要出现新的十六进制色值（品牌标识色块沿用现有色值，不受此限制）。
- 动效：颜色和透明度变化 260ms，位移 480ms，默认缓动 `cubic-bezier(.25,.8,.25,1)`，回弹 `cubic-bezier(.3,1.4,.5,1)`。只对 `transform` 和 `opacity` 做动画。
- 所有可点元素热区不小于 44×44。
