# 前后端联调说明

当前订阅业务通过 NestJS API 读写。页面不再读取或写入原来的本地订阅、设置缓存，也不会在断网时生成本地演示数据。旧缓存没有被删除或自动上传。

## 启动与地址

在项目根目录执行：

```powershell
pnpm --dir backend install --frozen-lockfile
pnpm --dir backend run start:dev
```

默认端口是 3001，健康检查地址为 `http://localhost:3001/api/v1/health`，Swagger 为 `http://localhost:3001/docs`。可用后端环境变量 `APP_PORT` 更改端口。

使用 HBuilderX 打开 `subscription` 并运行到 H5 或微信开发者工具。前端仍沿用现有 HBuilderX 项目，不需要创建新的 Vue CLI 工程。

编辑 `api/config.js`：

```js
export const API_CONFIG = {
  baseUrl: 'http://localhost:3001/api/v1',
  timeout: 10000,
  demoUserId: 'demo-user'
}
```

- 浏览器本机调试可使用默认地址。
- 手机真机中的 localhost 指手机自身，请改为运行后端的电脑局域网地址，确认设备网络可达和端口可访问。
- 发布前配置实际 HTTPS 接口域名及微信小程序请求域名；开发工具的本地调试设置不等于发布环境配置。
- 微信开发者工具本地调试已在 `project.private.config.json` 设置 `setting.urlCheck=false`。如果工具仍提示“request 合法域名列表”，打开右上角“详情 → 本地设置”，勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，然后点击“编译”。这个选项只用于开发调试，发布前必须恢复为校验开启并使用 HTTPS 域名。
- `demoUserId` 仅作为 `x-demo-user-id` 请求头隔离演示数据。默认用户有九条种子订阅；换成其他标识可测试空账户。该标识不是安全认证，不能用于正式上线。

## 实现位置

| 文件 | 作用 |
| --- | --- |
| `api/config.js` | 服务地址、超时、演示用户 |
| `api/request.js` | uni.request 封装，HTTP/网络/校验错误处理 |
| `api/subscriptions.js` | 资源接口、中文展示值与英文枚举转换、时间与历史转换、列表翻页 |
| `pages/subscription/subscription-remote.js` | 远程加载、写入、刷新、统计与提醒状态 |
| `pages/subscription/subscription-page-logic.js` | 页面导航、表单、筛选和日历展示 |

## 接入范围与行为

- 订阅列表读取全部分页，包含软删除记录；筛选和日历基于这些服务端记录展示。
- 点击详情重新获取单条记录。新增、编辑、复制、暂停、恢复、归档、取消和回收站操作均经过服务端。
- 复制先打开预填表单，保存时才创建新记录并检查额度。
- 确认付款携带本期 `billingDate`，同一账期重试不会再次推进日期。一次性项目完成后归档；十分钟内可撤销。
- 设置、模拟会员、表单元数据、统计和站内提醒列表均读取相应接口。
- 写入期间锁定重复提交，只在后端成功响应后更新页面；成功后的刷新失败会单独提示，不会当成写入失败。
- 网络错误不会自动重发写请求。结果不确定时须先刷新确认，避免重复新增。
- 统计切换币种时丢弃过期响应，避免较慢的旧请求覆盖当前币种。
- “重新加载数据”只重新读取服务端，不清空记录。

## 验证

前端请求、转换、失败状态和请求乱序测试（Node.js 22）：

```powershell
node --test subscription/tests/api.test.mjs
```

后端构建、测试、检查：

```powershell
pnpm --dir backend run build
pnpm --dir backend run test --runInBand
pnpm --dir backend run lint
```

真实 HTTP 联调测试（先安装并构建后端）：

```powershell
node --test subscription/tests/api-integration.test.mjs
```

联调测试会启动一个独立 Nest 进程内实例、使用临时端口和专用演示用户，测试完关闭；不会调用当前正在运行的后端。覆盖页面新增、编辑、续费撤销、暂停恢复、复制、删除恢复、设置、会员、一次性完成以及不同演示用户的数据分区。

手动验收：用开发者工具检查请求成功；保存后切换列表、首页、日历及统计确认一致；停止后端验证重试提示；启动后端刷新，确认显示服务端重置后的数据；真机确认地址可达。

## 当前边界

- 后端数据仅存于内存，服务重启会重置。尚未实现数据库和正式账号体系。
- 微信授权与发送没有闭环，因此页面明确展示“仅站内提醒”；稍后处理只保存待办状态，不承诺某个时间发送消息。
- 每周摘要开关仅保存偏好；会员开通和恢复只是模拟状态，不发起支付。
- 统计沿用当前后端口径：月均与年度为折算估算，六个月趋势为月均投影；未来三十天按每条记录的下一次扣费汇总，尚未展开窗口内多次扣费。
- CSV 在前端从已读取的服务端记录生成。H5 下载文件，其他端复制表格文本；正式导出接口和账号注销尚未实现。
- 自动测试覆盖逻辑和 HTTP 契约，不替代 HBuilderX 编译及微信真机验收。
