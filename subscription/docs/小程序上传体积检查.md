# 小程序上传体积检查

2026-10-30 上传失败提示 80051、source size 4971KB exceed max limit 2MB。主要体积来自全量拷贝的静态图片和示例资源。

项目根 project.config.json 的 packOptions.ignore 排除未用头像、演示资源、未引用的 Vant 文件和升级示例静态资源；源码文件均保留，分享封面与现有页面功能不变。HBuilderX 重新发行时会继承配置。

实测 HBuilderX 内置 uni-app 5.26 编译器生产构建成功。扣除 ignore 规则后，待上传文件总大小为 1,996,696 字节（向上取整 1950KiB），小于 2MiB。此统计包含配置等辅助文件，为本地保守统计，实际以微信开发者工具上传校验为准。

重新在 HBuilderX 选择「发行 → 小程序-微信」，不要直接重复上传旧编译包。如果通过微信开发者工具上传，先重新编译，再确认它打开的是最新生成目录。

编译后可在仓库根执行：

```bash
pnpm --dir subscription check:mp-size
```

也可指定编译输出目录：

```bash
node subscription/scripts/check-mp-package-size.mjs subscription/.preview/package-size/mp-weixin
```

脚本检查分享封面是否保留，并在体积超过 2MiB 时失败。当前仅有主包；引入分包后需扩展为逐包检查。
