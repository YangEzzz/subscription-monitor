## 配置与部署

本地后端配置放在 `backend/.env`，生产服务器配置放在 `deploy/.env.production`。这两个文件已被 Git 忽略，AppSecret 不写入前端。

```dotenv
WECHAT_APP_ID=wx639160564da9289a
WECHAT_APP_SECRET=<微信公众平台的小程序密钥>
AUTH_TOKEN_SECRET=<独立生成的随机签名密钥，至少32字节>
AUTH_TOKEN_TTL_SECONDS=604800
```

AppSecret 来源：微信公众平台小程序后台 → 开发管理 → 开发设置 → 开发者 ID → AppSecret。
签名密钥可在服务器使用 `openssl rand -hex 32` 生成。
生产配置沿用已有数据库密码和域名，仅增加上述四项，然后在服务器项目目录执行：

```bash
sudo docker compose --env-file deploy/.env.production up -d --build api
```

微信后台的 request 合法域名应包含 `https://subscription.yangezzz.top`。
前端当前请求地址为 `https://subscription.yangezzz.top/api/v1`，本地测试须将 `api/config.js` 改为本地后端地址。

## 登录与数据

首次打开自动调用微信登录。并发请求共享一次登录，令牌存于本机；失效后重新获取微信 code。
服务器拒绝伪造用户请求头，订阅、统计、设置、会员和提醒按微信账号隔离。首次真实账号为空，不迁移共享演示数据。
读请求的 401 最多重登并重试一次；写请求不会自动重发，保留输入，重新操作即可。
登录不自动读取头像、昵称或手机号；账号额度使用后端状态，会员购买暂未开放；微信通知须用户授权，接入与部署见仓库 deploy/微信通知部署.md。
