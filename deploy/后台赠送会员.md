# 后台赠送永久会员

入口：用户列表 → 搜索用户 ID → 查看用户详情 → 会员管理 → 赠送永久会员。

填写 2–200 字原因并核对用户 ID，点击「确认赠送永久会员」。用户刷新会员状态后获得永久权益和不限订阅数量。已有正式会员不会覆盖；模拟权益可升级。重复请求不会重复生成操作记录。

接口：`GET/POST /users/:userId/membership`，使用现有后台来源校验和管理员会话。POST 只接受业务字段 `note`，操作人由会话确定。来源记为 `admin`，不产生支付订单或收入；赠送记录存入 `admin_membership_grants`，与权益同事务写入。

部署时先执行数据库迁移（包含 `20261027000000_admin_membership_grants` 和 `20261027010000_admin_membership_revocations`），再重建后端和管理端。沿用项目部署命令：

```bash
docker compose --env-file deploy/.env.production up -d --build api admin
```

Compose 的 migrate 服务执行数据库迁移，成功后才启动 API；独立启动后端则先在 backend 执行 `pnpm db:deploy`。

`ADMIN_MEMBERSHIP_GRANTS_ENABLED` 默认开启，设为 `false` 禁用。`pnpm start:local` 的只读数据库环境固定关闭；本功能不绕过数据库只读保护。提交超时或失败后，先点「刷新会员状态」确认结果，再决定是否重新提交。

## 取消会员资格

同一用户详情的「取消会员资格」支持取消赠送、付费、历史及模拟权益。填写 2–200 字原因，核对用户 ID 和影响后点击「确认取消会员资格」。恢复免费版 10 条额度，已有订阅、历史记录不删除，已有订阅仍可编辑；超出额度时禁止新增或恢复订阅。

此操作不自动退款，不修改支付订单或收入。付费订单退款仍通过订单详情办理。支付核对识别原订单的管理员主动取消，不将其误报为权益丢失，其他支付凭据问题继续提示。

接口为 `POST /users/:userId/membership/revoke`，提交 `note` 及读取时的 `expectedMembership` 权益快照。账号锁内核对 status、plan、source、sourceOrderId、startedAt，状态变化返回 409，刷新后重新核对；已是免费版的重复取消不重复记账。操作以 action=revoke 存入原审计表，保留取消前完整权益、操作人、原因、时间；赠送记录 action=grant。取消后的来源 admin_revoked 保留原订单关联，不伪装成退款。

赠送与取消共用 `ADMIN_MEMBERSHIP_GRANTS_ENABLED` 环境开关；本地只读环境两者均禁用。
