# 最近访问 IP 和时间

2026-10-16 按用户要求增加。只覆盖每个账号最近一条记录，不收集完整访问历史、不查询位置、不从历史日志回填。成功微信登录和通过 Bearer 认证的请求更新；匿名请求、支付推送和后台读取不会更新。相同 IP 最多每60秒写入一次，IP 变化立即写入，不允许旧请求覆盖较新记录。保存失败不会使登录或业务操作失败，日志只记录固定告警，不输出 IP 或令牌。

数据库为 `app_users.last_access_ip`（IPv4/IPv6）与 `last_access_at`（UTC）。管理 `/data?section=users` 返回，表格及详情按北京时间展示；旧后端字段缺失或历史数据为空时显示“—”。小程序响应和登录令牌不包含访问字段。

## 代理配置

默认不信任转发头。`TRUSTED_PROXY_CIDRS` 为逗号分隔的直连代理 IP/CIDR；只在 socket 来源命中时读取一个有效的 `X-Real-IP`，忽略 `X-Forwarded-For`，可信代理缺失/无效的头不记成代理 IP。未命中的连接只使用 socket 地址。IPv4-mapped IPv6 会规范化，非法地址、端口、地址列表被拒绝。

生产宿主 Nginx 的**小程序 API 转发 location** 必须保留以下行（现有 `deploy/nginx/subscription-monitor.conf.example` 已包含）：

```nginx
proxy_set_header X-Real-IP $remote_addr;
```

不要使用客户端提交的 `$http_x_real_ip`。Nginx 前面如果还有 CDN 或其他代理，需要先配置该网关的可信 real_ip 来源；本项目不自动信任 CDN 请求头。不要配置 `0.0.0.0/0` 或所有内网地址为可信代理。API 宿主发布端口继续绑定 `127.0.0.1`。

现有拓扑为宿主 Nginx → Docker API，更新脚本会读取 API 容器当前的网络网关，将确切地址写入生产 `TRUSTED_PROXY_CIDRS`；不改 Nginx、不改支付开关、不覆盖其他配置。网络网关改变时需重新运行脚本。部署前应核对当前 Nginx 的 API location 仍保留上述行。

## 服务器更新

```bash
cd /opt/subscription-monitor
git pull --ff-only origin main
bash deploy/update-user-access.sh
```

脚本先备份环境和数据库，再构建 API、执行新增 nullable 字段迁移、重建 API。无需重新编译小程序。本机后台仍通过已恢复的 `/admin/` 只读接口访问服务器，刷新即可看到新列；服务器自行托管的 Vue 后台如需同步列展示，再构建并更新 admin 服务。

更新后打开小程序访问一次，再刷新后台用户列表，核对最近访问时间和 IP。旧账号在下次访问前为空是正常现象。部署没有移除旧字段或修改已有订阅、订单、权益；回滚 API 时可保留这两个新增字段。

用户隐私告知应与实际的 IP、时间采集用途保持一致。最近记录随账号数据保留并在账号数据删除时一并删除，不向其他普通用户返回。
