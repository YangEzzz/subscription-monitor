# 后台登录与支付核对

## 当前实现与边界

本地前端 → 本地管理后端 → 线上数据库。管理接口现在要求独立管理员会话，微信小程序 Bearer 令牌不作为管理员凭据。登录、退出和会话检查使用管理端口，业务 API 保持原认证。管理员登录不写入用户表，不混入小程序注册/登录记录。

新支付核对仅查询已有表，不需要新增迁移，不向微信发请求，不修改订单、会员或退款。线上服务代码本次没有部署；本地鉴权不意味着旧线上管理入口已经获得应用会话保护。旧线上入口应继续保留 Nginx 认证与访问限制，更新后前后端需配套部署。

## 管理员初始化

本机已初始化 admin。用户名/哈希在忽略提交的 backend/.env.local；初始登录信息在 backend/.env.admin-initial，仅供本机读取。删除初始信息文件不影响哈希或登录。

在项目根目录运行（需要 backend 依赖已安装）：

```bash
node backend/scripts/admin-setup.cjs
```

默认生成随机密码，密码只写入环境文件同目录的 `.env.admin-initial`，不输出日志。设置指定密码可以用 `--password-stdin` 从标准输入读取，至少12位；不要把密码作为命令行参数。已有账号不会被默认覆盖。重置添加 `--reset`，并重启本地启动脚本，使新环境变量加载。`--username` 可指定账号名。

部署时可以在服务器项目目录运行 `node backend/scripts/admin-setup.cjs --env-file deploy/.env.production`，或把本机生成的 ADMIN_USERNAME、ADMIN_PASSWORD_HASH 安全复制到生产私有环境文件。哈希含 `$`，Compose 环境文件必须用单引号包住哈希值，避免变量展开。不要把 `.env.admin-initial` 或环境文件提交到仓库。

配置：`ADMIN_USERNAME` 默认 admin；`ADMIN_PASSWORD_HASH` 为初始化脚本生成的 scrypt 哈希。未配置/无效哈希时登录拒绝开放，数据接口一律401。生产环境会话 Cookie 自动 Secure，应通过 HTTPS 访问。

## 会话与代理

- POST `/login`，JSON username/password；错误提示不区分账号或密码。
- GET `/session` 只返回配置状态、是否登录和管理员名，不返回哈希或令牌。
- POST `/logout` 撤销服务器会话并清除Cookie。
- 数据GET `/overview`、`/data` 必须携带合法会话，未登录/过期返回401。

Cookie 为 HttpOnly、SameSite=Strict、8小时固定有效期；随机32字节令牌，服务器只保留摘要。会话在内存中，服务重启/重置账号后需要重新登录。退出后令牌立即不可用。每个直连地址15分钟最多5次错误尝试；计数在验证前更新，限制并发尝试，过期自动清理。管理端仍只接受本机/受控代理Host、来源与请求头，移除了旧 Origin:null 无鉴权访问路径。

前端凭据只用于登录请求，不保存在 localStorage/sessionStorage；401会清除当前用户数据并回到登录页。Vite同源代理转发Cookie。Nginx后台API代理已允许GET/POST，后端仅允许登录/退出使用POST，数据写接口仍不存在。继续使用相对 `./api/` 支持 `/admin/` 子目录。

## 统计口径

- 账号总数：当前用户表行数。
- 会员人数：status=active且plan=member，排除source=simulation；历史赠送权益仍计入。
- 有效支付金额：人民币CNY、真实渠道wechat/virtual且当前status=paid订单金额合计；排除模拟、待支付、失败、已取消、已退款订单。不等同于微信平台结算收入，不汇总其他币种。
- 支付待核对：下列规则命中的订单或权益对象数。一个订单只展示优先级最高的问题，修复后可能出现该订单的其他待核对项。

列表为累计当前库状态，读取时间显示于页脚；不是按日流水或平台对账单。

## 支付与权益规则

1. 真实已支付订单，但账号没有active/member权益。
2. 真实已支付订单缺少平台交易号或支付时间。
3. 虚拟支付已支付，但发货确认时间为空。
4. 真实订单发起支付超过15分钟，仍为pending；这表示待确认，不等于支付失败。仅创建但未发起支付的订单不纳入。
5. 真实来源的有效会员权益没有关联到同用户的真实已支付订单。

模拟支付不进入核对队列，legacy来源权益不要求支付订单。每行详情提供订单状态、平台交易号、发起/支付/发货时间、当前会员状态等已有证据；不返回支付密钥、微信OpenID或用户会话。

## 验证

后端82项测试、前端19项浏览器测试和6项数据单测通过；覆盖未登录、错误密码、限流、退出撤销、会话过期、数据清除、统计排除模拟/退款、多种核对场景。`node backend/scripts/verify-admin-billing.cjs` 用只读PostgreSQL会话和合成CTE验证SQL，不写真实表。

实际本地链路验证：未登录401，登录后读取真实库成功，支付队列可查询，退出后再次401。当前数据13账号、1正式会员、¥9.90有效支付、0支付待核对，不据此断言微信平台账单已对账。生产应用未部署。
