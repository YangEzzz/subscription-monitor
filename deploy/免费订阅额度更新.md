# 免费10条订阅与会员推荐页

免费额度由后端 `FREE_SUBSCRIPTION_LIMIT` 从5调整为10，永久会员不限数量。不存在清理或截断既有记录的操作；取消、暂停、归档仍沿用原计数规则，回收站不占额度，历史账单保留。新增和恢复继续使用按账号串行的服务端额度校验。

小程序第11条新增直接展示会员推荐态，读取真实商品价格、可售状态和支付渠道，沿用现有虚拟支付/模拟支付开关与设备支持限制。用户主动开通，服务端确认权益后才能继续添加，不自动付款或保存。

提交并推送代码后，在服务器执行：

```bash
cd /opt/subscription-monitor
git pull --ff-only origin main
sudo docker compose --env-file deploy/.env.production config --quiet
sudo docker compose --env-file deploy/.env.production up -d --build api
sudo docker compose --env-file deploy/.env.production ps
curl -fsS http://127.0.0.1:3001/api/v1/health
```

然后使用HBuilderX重新编译并发布小程序。不需要数据库迁移、新环境变量或重新配置商品价格；服务器已有支付开关继续生效。

验收：非会员已有9条时还能正常新增第10条；满10条再点底部新增出现推荐页，返回不丢草稿；删除一条后可再次新增，历史账单仍在；开通成功后点击继续添加进入原表单。付款取消、支付结果待确认、商品未开放和设备不支持时不能当作已开通。正式会员可以创建第11条，退款后已有超额记录保留并限制继续新增。
