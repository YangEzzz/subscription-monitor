# 临时管理后台

支持概览、用户/订阅/通知列表、搜索、分页和刷新。只查询，不修改用户数据或发送消息。

## 直接打开 HTML

双击 `backend/public/admin.html`，自动请求 `https://subscription.yangezzz.top/admin/` 并读取后端真实数据。不用部署 HTML、不用启动本地服务，也不用填写密钥。地址可在页面中修改。

按用户选择，此后台不提供身份认证。后端允许 Origin 为 `null` 的文件请求；这是浏览器跨域来源限制，不是身份验证。

## 服务器更新命令

先将本次代码推送到 Git，再在服务器运行（项目目录不同则替换路径）：

```bash
cd /opt/subscription-monitor
git pull --ff-only
nano deploy/.env.production
```

确保环境文件包含：

```dotenv
LOCAL_ADMIN_ENABLED=true
```

无需配置 `LOCAL_ADMIN_FILE_TOKEN`，旧配置可以删除。

```bash
sudo docker compose --env-file deploy/.env.production up -d --build api
sudo docker compose --env-file deploy/.env.production logs --tail=50 api
```

编辑域名现有 Nginx 配置（文件位置不同则替换）：

```bash
sudo nano /etc/nginx/sites-available/subscription-monitor
```

在 `subscription.yangezzz.top` 的 **HTTPS server 块内**添加以下配置，与现有 `location /` 同级。如果已添加过 `/admin/`，替换原来的块：

```nginx
location /admin/ {
    if ($http_origin != "null") { return 403; }

    proxy_pass http://127.0.0.1:3002/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Origin $http_origin;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_connect_timeout 10s;
    proxy_read_timeout 30s;
}
```

保留现有证书和其他接口配置，检查通过后重载：

```bash
sudo nginx -t && sudo systemctl reload nginx
curl -i -H 'Origin: null' https://subscription.yangezzz.top/admin/overview
```

验证请求应返回 HTTP 200 和 JSON 概览。随后在电脑上双击 HTML，页面会自动读取数据。直接在浏览器地址栏访问线上 `/admin/` 会被来源规则拒绝。

## 本机后端

在 `backend/.env` 中设 `LOCAL_ADMIN_ENABLED=true` 并启动后端。双击 HTML 后将地址修改为 `http://127.0.0.1:3002` 并点击「连接后台」，或直接打开这个 HTTP 地址。线上管理端口继续绑定宿主机 `127.0.0.1:3002`，由 Nginx 转发。

关闭后台：将 `LOCAL_ADMIN_ENABLED=false` 并重启后端。无需数据库迁移。

## 数据范围

显示跨账号的数据，但不返回微信 OpenID、AppSecret、登录令牌或授权凭证。每页 20 条，搜索仅匹配界面说明的字段。订阅总数不含已删除/演示记录；通知待排查数包含失败和结果未知记录。内存仓库仅供开发，线上数据来自 PostgreSQL。
