# 临时管理后台

第一版：运行概览、用户列表、订阅查询（含已删除记录）、微信通知发送记录、搜索、服务端分页和刷新。
后续：订阅编辑/恢复、会员额度管理、通知失败重试、操作审计、管理员权限。

当前版本仅供本机访问，无登录；只查询，不发送消息或修改用户数据。后台通过独立 HTTP 端口提供，不挂载到小程序 API 或 Nginx。默认关闭。

## 本地启动

在 `backend/.env` 中加入：

```dotenv
LOCAL_ADMIN_ENABLED=true
```

启动后端后打开 `http://127.0.0.1:3002`。HTML 文件为 `backend/public/admin.html`，无需安装前端依赖或构建页面；直接双击文件不能查询数据。

## Docker 服务器

在 `deploy/.env.production` 中加入 `LOCAL_ADMIN_ENABLED=true`，然后在项目目录运行：

```bash
docker compose up -d --build api
```

Compose 只将管理端口发布到服务器的 `127.0.0.1:3002`。容器内部监听 `0.0.0.0` 是容器网络所需，勿把宿主机端口改为公网监听，也勿添加 Nginx 转发。

如果需要从自己电脑查看远程服务器的后台，在电脑终端建立 SSH 隧道（替换服务器地址）：

```bash
ssh -N -L 3002:127.0.0.1:3002 root@服务器地址
```

保持此窗口打开，在电脑浏览器打开 `http://127.0.0.1:3002`。

关闭后台：删除环境变量或设为 `LOCAL_ADMIN_ENABLED=false` 并重启后端。无需数据库迁移。

## 数据范围

显示跨账号的数据，但不返回微信 OpenID、AppSecret、登录令牌或授权凭证。列表每页 20 条，搜索只匹配界面说明的字段。订阅总数不含已删除/演示记录；通知待排查数为失败和结果未知记录总和，不代表需要重发。
账号 ID 和财务数据仍是敏感信息，后台只用于自己的电脑或服务器本地。内存数据仅供开发，生产数据来自 PostgreSQL。
