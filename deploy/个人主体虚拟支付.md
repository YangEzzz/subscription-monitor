## 配置与部署

敏感配置只在服务端 `.env` 或部署环境设置；不能提交到 Git、小程序或日志。`backend/.env` 已设置用户提供的 AppID、OfferID、现网 AppKey；沙箱密钥不参与现网签名。此次补齐了原本缺失的消息推送 Token 和 EncodingAESKey，在文件中复制到 MP 后台，不在聊天中输出。

```dotenv
WECHAT_VIRTUAL_PAY_ENABLED=true
WECHAT_VIRTUAL_PAY_OFFER_ID=1450679545
WECHAT_VIRTUAL_PAY_APP_KEY=现网密钥
WECHAT_VIRTUAL_PAY_PRODUCT_ID=lifetime_member
WECHAT_VIRTUAL_PAY_NOTIFY_TOKEN=与MP消息推送一致的Token
WECHAT_VIRTUAL_PAY_ENCODING_AES_KEY=与MP一致的43字符EncodingAESKey
WECHAT_VIRTUAL_PAY_IOS_ENABLED=false
MEMBERSHIP_SIMULATION_ENABLED=false
```

还需正确的 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、不少于32字节的 `AUTH_TOKEN_SECRET`，生产使用 PostgreSQL。先备份数据库，再运行现有 `docker compose run --rm migrate` 应用迁移，构建并更新 API。迁移新增加密会话及支付发起、发货确认时间字段，不修改旧订单金额或权益。普通支付 `WECHAT_PAY_*` 配置退役，应删除；若仍开启旧支付开关，服务拒绝启动。

MP【开发与服务→开发管理→消息推送】配置：

- URL：`https://subscription.yangezzz.top/api/v1/membership/virtual/notify`
- Token / EncodingAESKey：与部署服务端环境变量完全一致。
- 加密方式：安全模式；XML、JSON均可。GET验签验证URL，POST接收加密推送。
- 不要覆盖已有消息接收服务而丢失其他事件；当前支付接收地址只处理虚拟支付发货和退款事件。若已有其他消息类型，共用URL时需统一路由。

## 订单、安全和退款

后端固定990分和购买数量1，现网env=0。AppKey签名覆盖实际传输的完整JSON字符串；用户态签名使用服务端加密保存的最新session_key，前端发起支付前重新登录。签名不返回密钥。首次下发收银台参数会保存paymentRequestedAt；重复请求只查单，不再次拉起相同业务单号。取消或网络不确定时保留订单，禁止直接授予权益；已有待确认订单会复用，需等待平台确认或关闭后再创建。若参数响应丢失且平台始终未创建订单，需运营核实后关闭本地订单，不能盲目重新签发或判定已支付。

消息推送通过SHA1验签、AES-256-CBC解密、AppID校验，拒绝明文推送、过期签名及DTD/entity报文。发货校验账号、商品、环境、数量、金额、平台交易号；按平台wx_order_id（数据库唯一transactionId）幂等。事务内保存订单和权益，重复推送不重复开通。iOS无WeChatPayInfo时通过平台查单恢复可信交易号。

每5分钟分页查单，查询待支付和已支付未确认发货的订单；查到已支付时先保存权益，再调用notify_provide_goods。确认失败保留记录，下次重试；服务重启仍可从数据库恢复。退款成功推送按平台交易号和业务单号校验；全额退款仅撤销对应订单发放的权益，旧订单退款不会撤销新订单或其他来源权益，退款先到再收到支付也不会重新开通。部分退款保留永久权益，由运营处理。

用户退款：安卓联系开发者处理，iOS通过Apple办理，服务端成功退款推送再同步权益。当前不提供主动发起退款的管理按钮，可在平台后台操作。安卓技术服务费1%、结算T+3；iOS佣金12%、结算45–60天。个人主体全终端月支付限额10万元。会员购买页已展示这些规则，当前入口已按用户要求开启供测试。

## 现有服务器更新命令

以下假设项目目录为 `/opt/subscription-monitor`，其他路径替换后执行。保留服务器原有数据库、AppSecret和AUTH_TOKEN_SECRET；不要用本地完整.env覆盖生产文件。将本地已配置的现网AppKey、消息Token和EncodingAESKey填入服务器deploy/.env.production，开启WECHAT_VIRTUAL_PAY_ENABLED，关闭MEMBERSHIP_SIMULATION_ENABLED和旧WECHAT_PAY_ENABLED，iOS保持false。

```bash
set -e
umask 077
cd /opt/subscription-monitor
git pull --ff-only origin main
nano deploy/.env.production
chmod 600 deploy/.env.production
sudo docker compose --env-file deploy/.env.production config --quiet
mkdir -p backups
sudo docker compose --env-file deploy/.env.production exec -T postgres \
  sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' \
  > "backups/pre-virtual-pay-$(date +%F-%H%M%S).dump"
sudo docker compose --env-file deploy/.env.production build api
sudo docker compose --env-file deploy/.env.production run --rm migrate
sudo docker compose --env-file deploy/.env.production up -d --force-recreate api
sudo docker compose --env-file deploy/.env.production ps
curl -fsS http://127.0.0.1:3001/api/v1/health
sudo docker compose --env-file deploy/.env.production logs --tail=80 api migrate
```

暂缓MP消息推送时仍要填写服务端Token、EncodingAESKey以满足安全配置；它们可先保存，后续在MP填写相同值。本次现网env=0，测试付款会真实扣9.90元。查单兜底每5分钟运行，退款消息同步在MP未配置前不可验收。
